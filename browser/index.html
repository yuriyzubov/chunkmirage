chunkmirage demos

Each runs in this browser with nothing to install: images are read from public buckets, and every chunk on screen is computed here when the viewer asks for it (chunkmirage's own Python ops in Pyodide, or the registration solver on your GPU). Each also shows the command that serves the same from Python, for Neuroglancer, Fiji, napari or a dask script; one, whose data no browser page may read, runs from Python only. Documentation.
